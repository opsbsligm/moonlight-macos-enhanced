# HOME-PC 失联事件:GameStream 兼容层半死 + 配对被重置(2026-09-30)

用户报告"本机连不上远端"。本文只写探针实测事实;结论与恢复路径都标注证据强度。

## 探针事实(本机执行,非推测)

| 探针 | 结果 | 含义 |
| --- | --- | --- |
| ICMP 192.168.3.110 | 1.4ms 通 | 主机在网 |
| TCP 135/139/445/3389/22 | 全开 | Windows 活着 |

## 结论(分层)

1. **根因(强证据)**:远端 Sunshine 的 GameStream 兼容监听(47984/47989/48001)半死——TCP accept 残留、应用层全灭。Sunshine 本体活着,所以是它的**流服务监听器**挂了,不是整机问题。
2. **并发事实(强证据)**:客户端侧该主机配对丢失(未配对)。远端 22 端口开着但本机无可用凭据(密钥 BatchMode 实测不通),无法从本机取证远端昨夜发生了什么;最合理解释是远端机器或 Sunshine 昨晚重启/更新,GameStream 证书或配对状态被重置。标注:远端侧动作为**未证实**。
3. **客户端(已排除)**:1720 无启动回归,证据为上表最后三行。

## 恢复路径(远端操作,按此顺序)

1. 重启 Sunshine 服务(RDP 已开放,或物理机):`net stop Sunshine` / `net start Sunshine`,或退出重开 Sunshine 托盘程序;
2. Sunshine Web UI(https://192.168.3.110:47990)确认 GameStream 客户端列表,清空旧 PIN 记录;
3. 本应用主机列表点 HOME-PC 重新配对(PIN 输入),客户端会重建 `moonlightSettings` blob——**届时本文件"实测配置"表(⌃⌥C / ⇧⌥ / 全屏锁定)仍然有效,因为那在主机配置层**;
4. 恢复判据:`printf 'reqdiscover' | nc -u -w 3 192.168.3.110 48001` 有二进制回包。
