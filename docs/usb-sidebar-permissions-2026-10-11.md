# USB：配置许可与串流操作分离

## 用户要求
设置仅配置允许重定向哪些设备；实际连接选择属于串流后的侧边控制栏。

## 本轮实现
- 设置首页：总许可、紧凑的本机设备列表、已配置的型号规则。
- 添加设备直接创建准确 VID/PID 型号规则，不把规则当成物理设备序列号许可。
- 重复规则不再追加；已有禁用规则仍在规则列表管理，不偷偷开启。
- 高级接口类别、手工编号输入、构建/驱动/主机审计分别折叠。
- 串流侧栏菜单新增 USB 设备子菜单，显示名称、类别与型号编号。
- 连接入口位于设备子菜单；当前缺少真实主机通道和可加载驱动，因此明确禁用，不产生假连接或假勾选。
- 每次侧栏菜单重建重新读取许可和设备，不持久化 session 选择、不新增后台枚举轮询。

## 边界与后续
本轮完成信息架构与连接入口迁移，不是 USB 传输链路完成。完整实现仍依赖设计文档 UNLOCK(stage3) 条件，以及真实主机 bind/state/item 和驱动生命周期接线。未来连接动作应使用串流 session 的设备注册表和回执，不得把当前白名单 verdict、视频已连接或用户点击当成设备连接成功。

## 验证
扩展既有 panel-model 门禁，验证权限精确添加、去重、侧栏入口、设备辨识、无运行链路时连接动作禁用及 AppKit 禁自动启用。保留旧策略/隐私/驱动边界门禁。真实 UI 需要 computer-use 服务可用；构建成功不能冒充视觉验收。

## 回滚
撤销本轮提交即可恢复旧布局；未修改协议、驱动或已存规则格式。

## 持续打磨 cp1：后台枚举

此前菜单重建同步扫描 IOKit；现移到 utility 队列，只将不可变设备快照交回主线程。仅允许一个扫描在途，正常开菜单复用两秒内同一串流代次的快照；手工刷新可绕过新鲜度，但不能绕过在途或停止保护。

采纳结果前核对真实串流代次、停止状态与主机 UUID。不以侧栏生命周期 token 判定过期，因为展开/收起也会改变该 token。扫描不强持有控制器；完成时不重建正在跟踪的菜单，下次打开读取新快照。菜单分别显示初扫、刷新、读取失败与成功空列表；现有列表刷新期间只作设备辨识，不代表实时接管状态。

共享 `USBScanPolicy.h` 的实际 C 决策经回放覆盖停止、重连、主机切换、强制刷新和去重，并用六个可编译变异确认回归会被拒绝。测试接入既有 panel-model 门禁，无新增绕过 CI 的独立测试入口。完整 USB 传输、热插拔持续跟踪和视觉/真实串流延迟验收仍未完成。

## 2026-10-12：设备页生命周期验证

设置内存探针现在交替请求串流页与设备页，恢复先前的页面选择，并在设备页等待扫描终态。访问循环放在应用完成启动后的阶段；启动前的 AX 只有顶栏占位内容，会误把设备页判为扫描超时。每个设备页最多等待 5 秒，记录 `read`、`unreadable` 或 `timeout`。`unreadable` 只表示扫描结束且总线不可读，不表示设备可用。

本机 Debug arm64 实际回放：4 次打开/关闭完成，页面请求 `[0,6,0,6]`，两次设备扫描均 `read`，报告无失败。标准泄漏扫描比较 1 次与 16 次访问，第一方泄漏字节与图数量均为 0 → 0，增长门禁通过。总计 240 字节、6 个非第一方泄漏块；这些结果只代表本次观察窗口。主机读取计数为零，没有可用于测量 fan-out 的泄漏主机，不调整既有所有权基线。

渲染和泄漏门禁均检查访问完整性、交替页面以及每次设备页扫描终态；自测保留缺访问、跳过设备页、缺扫描结果和超时反例。标准增长扫描要求至少相隔 10 次访问，参数不足在启动扫描前拒绝。

这些结果覆盖设置页出现/消失与扫描终态，不证明驱动设备接管、USB 数据传输、热插拔或串流时延。现场主机能力应答缺少 `usbRedirection`；DriverKit 分发签名、公证和主机通道仍需具备真实实现与验收证据。

### 2026-10-12：主机只读查询身份校正

现场对照同一客户端证书和同一 `/serverinfo` 端点：不携带
`uniqueid` 时 `PairStatus=0`，携带本机数据库的客户端 ID 时
`PairStatus=1`。诊断请求必须跟随 `HttpManager` 的真实请求形态，
不能将缺少客户端 ID 的结果解释为应用失配，也无需重新配对。
两次均返回 `SUNSHINE_SERVER_BUSY`、非零 `currentgame`，未返回
`usbRedirection`。busy 仅证明主机应用正在运行，不能单独证明用户
正在操作或存在活动客户端；未终止主机应用，真实串流 A/B 和 USB
完整传输仍未验收。不要在分享的诊断日志中暴露客户端 ID 或密钥。
