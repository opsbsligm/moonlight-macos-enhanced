## 二、本轮实测的用户配置（只读，未修改）

从 `defaults export std.skyhua.MoonlightMac2` 的 `*-moonlightSettings` blob（内层 bplist）解出，
不是全局默认值的推测：

| 范围 | 键 | 值 | 含义 |
| --- | --- | --- | --- |
| HOST-PC `86D1F81F…` | `displayMode` | 1 | 全屏 |
| HOST-PC | `mouseMode` | 0 | 锁定（相对）游戏鼠标 |
| HOST-PC | `edgeSensorSummon` | 缺失 → 继承全局 | 感应带启用 |
| 全局 | `edgeSensorSummon` | True | 同上 |
| HOST-PC | `streamShortcuts.openControlCenter` | keyCode 8 + `0xC0000` | **⌃⌥C** |
| HOST-PC | `streamShortcuts.releaseMouseCapture` | keyCode −1 + `0xA0000`，modifierOnly | **⇧⌥**（全局是 ⌃⌥，主机覆盖为 ⇧⌥） |
| HOST-PC | `captureSystemShortcuts` | True | 串流内接管系统快捷键 |
| 全部 | `…hideFullscreenControlBall` | 不存在 | 控制栏未被隐藏 |

结论：用户路径仍是**全屏 + 锁定游戏鼠标 + 感应启用 + 控制栏未隐藏**，
锁定模式入口（⌃⌥C 必定展开）与 ⇧⌥ 主动释放就是这台机器的真实组合。
